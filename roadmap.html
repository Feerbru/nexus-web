Ruta de Aprendizaje (Roadmap)

Seguí este orden lógico recomendable para construir una base sólida en desarrollo web front-end de forma progresiva.

1

1. HTML (Fundamentos de Estructura)

Paso Inicial

Comenzá aprendiendo la anatomía de una página web, el uso correcto de etiquetas semánticas, creación de encabezados, listas, tablas, enlaces y formularios accesibles.

2

2. CSS (Estilos y Layouts)

Diseño

Aprendé a darle estilo y color a tu sitio. Dominá el modelo de caja, posicionamiento, unidades relativas (rem, em, vh), Flexbox y CSS Grid para crear maquetaciones modernas.

3

3. JavaScript (Lógica e Interactividad)

Programación

Incorporá dinamismo a tus páginas. Entendé variables, condicionales, bucles, funciones, manipulación del DOM y captura de eventos del usuario.

4

4. Bootstrap (Framework CSS)

Productividad

Agilizá tu flujo de trabajo maquetando con el sistema de columnas de Bootstrap y reutilizando componentes estilizados como navbars, modales y tarjetas.

5

5. Git & GitHub (Control de Versiones)

Herramientas

Aprendé a guardar ramas de tu proyecto, gestionar cambios con commits y publicar tus repositorios en GitHub Pages para compartir tu código.

6

6. Proyecto Final Integrador

Meta Alcanzada

Integrá todos los conocimientos creando una plataforma web completa (como NEXUS Hub), puliendo la experiencia de usuario y aplicando buenas prácticas de código.
