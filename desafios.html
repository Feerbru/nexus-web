Desafíos Semanales

Retos cortos y focalizados en componentes específicos para agilizar tu velocidad de maquetación y ejercitar tu lógica.

Semana 1 Est. 2 horas

Crear una Landing Page de Producto

Diseñá una página promocional sencilla con un header llamativo, sección de características de 3 columnas y un llamado a la acción (CTA) al final.

Objetivo: Flexbox / Semantic HTML
Semana 2 Est. 1 hora

Diseñar una Navbar Responsive

Construí un menú de navegación que en pantallas grandes se muestre horizontal y en móviles se transforme en un menú hamburguesa desplegable.

Objetivo: Media Queries / Bootstrap Navbar
Semana 3 Est. 1.5 horas

Construir un Formulario Validado

Crea un formulario de registro con campos de usuario, clave y correo. Implementá validación con JS para dar feedback instantáneo antes del envío.

Objetivo: Eventos JS / Regex básico
Semana 4 Est. 2 horas

Crear una Galería de Imágenes Responsive

Maquetá una grilla de tarjetas visuales utilizando CSS Grid y agregá un efecto hover suave con transformación de escala en las fotos.

Objetivo: CSS Grid / Transiciones
